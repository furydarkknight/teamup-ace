# SentenceTransformer based on sentence-transformers/all-MiniLM-L6-v2

This is a [sentence-transformers](https://www.SBERT.net) model finetuned from [sentence-transformers/all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2). It maps sentences & paragraphs to a 384-dimensional dense vector space and can be used for semantic textual similarity, semantic search, paraphrase mining, classification, clustering, and more.

## Model Details

### Model Description
- **Model Type:** Sentence Transformer
- **Base model:** [sentence-transformers/all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2) <!-- at revision 1110a243fdf4706b3f48f1d95db1a4f5529b4d41 -->
- **Maximum Sequence Length:** 256 tokens
- **Output Dimensionality:** 384 dimensions
- **Similarity Function:** Cosine Similarity
- **Supported Modality:** Text

### Full Model Architecture

```
SentenceTransformer(
  (0): Transformer({'transformer_task': 'feature-extraction', 'modality_config': {'text': {'method': 'forward', 'method_output_name': 'last_hidden_state'}}, 'module_output_name': 'token_embeddings', 'architecture': 'BertModel'})
  (1): Pooling({'embedding_dimension': 384, 'pooling_mode': 'mean', 'include_prompt': True})
  (2): Normalize({})
)
```

## Usage

### Direct Usage (Sentence Transformers)

First install the Sentence Transformers library:

```bash
pip install -U sentence-transformers
```
Then you can load this model and run inference.
```python
from sentence_transformers import SentenceTransformer

# Download from the 🤗 Hub
model = SentenceTransformer("sentence_transformers_model_id")
# Run inference
sentences = [
    'skills: Machine Learning CSS Cybersecurity Flask Django Graphic Design Project Management. interests: Artificial Intelligence Social Impact Tech. project_experience: Designed a IoT mobile interface using Flask and Django Contributed to an open-source CSS library focused on recommendation Implemented a productivity system using Cybersecurity and Flask. bio: Andre Carter is a motivated intermediate student from Stonecrest College with a knack for Cybersecurity. They are passionate about applying technology to Artificial Intelligence and have side projects in Social Impact Tech using Machine Learning.. preferred_roles: UI/UX Designer. experience_level: Intermediate',
    'required_skills: Flask Project Management CSS. preferred_skills: MongoDB SQL HTML. interests: Open Source Cloud Architecture Web Development. team_description: Spark Lab is developing a web-based disaster response platform. Current members bring Data Science, Python, Data Analysis, but the team needs Flask expertise to complete the product.. preferred_roles: Full Stack Developer UI/UX Designer. preferred_experience: Advanced',
    'required_skills: Presentation Communication Python. preferred_skills: Flask Machine Learning Computer Vision. interests: Research & Academia Bioinformatics. team_description: Beta Builders is tackling a accessibility challenge in healthcare by applying Flask, CSS, HTML. The team is actively seeking Presentation capabilities.. preferred_roles: Backend Developer Machine Learning Engineer Research Lead. preferred_experience: Advanced',
]
embeddings = model.encode(sentences)
print(embeddings.shape)
# [3, 384]

# Get the similarity scores for the embeddings
similarities = model.similarity(embeddings, embeddings)
print(similarities)
# tensor([[1.0000, 0.6500, 0.4035],
#         [0.6500, 1.0000, 0.3681],
#         [0.4035, 0.3681, 1.0000]])
```
